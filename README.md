# robotont-mechanics

This repository contains models of mechanical parts of Robotont.
The latest release of Robotont is gen3.0-lite.
Gen 3 is developed in SolidWorks (Student version).
3MF files for 3D-printing are provided.

## Chassis overview

The main chassis is divided into 4 modules:

- Frame module
- Motor module
- Computer module
- Battery module

## Production

To reproduce Robotont, production files are provided in [production](main-chassis/production/) folder.
The 3MF files contain the print settings for printers Prusa XL, Prusa CORE One and Bambu Lab A1.
The Prusa XL is used for the top and bottom plates; the Prusa CORE One is used for the wheel adapter and washer; the Bambu Lab A1 is used for the battery module, computer module, cable box and motor mounts.

To develop and change Robotont, SolidWorks model files are provided, along with STEP for use with other modeling software.
